Bulk Edit Game Data

Upload a CSV to update Performance, Attributes, and Metadata columns for many games at once. Matched by gameId.

Steps:

  1. Download CSV template (pre-filled with current values) — OR export from the All Games > Games tab.
  2. Edit only the columns you want to change. Leave a cell blank to keep its current value. Do not change the gameId column.
  3. Editable fields: rtp, maxWin, vol, theme, release, kz, promo, tags (semicolon-separated), notes, visible (true/false), maint (true/false).
  4. Upload your edited CSV below, review the change preview, then apply.
